# Content Security Policy inventory (2026-10-30)

Source of truth: `app/csp.php` (headers sent from `app/bootstrap.php` on every PHP response).
`docker/000-default.conf` keeps `Content-Security-Policy: frame-ancestors 'self'` (always set) as a
backstop for responses PHP never touches. Media responses (`media_show`, `media_variant`) replace
the PHP enforced header with their own `default-src 'none'; sandbox`.

## Headers

Enforced:

```
Content-Security-Policy: object-src 'none'; base-uri 'self'; form-action 'self' https://accounts.google.com; frame-ancestors 'self'
```

Report only (nonce changes on every response):

```
Content-Security-Policy-Report-Only: default-src 'self'; script-src 'self' 'nonce-<n>' https://cdnjs.cloudflare.com; style-src 'self' 'unsafe-inline' https://cdnjs.cloudflare.com; img-src 'self' data: blob: https:; font-src 'self'; connect-src 'self'; media-src 'self' blob:; worker-src 'self'; manifest-src 'self'; frame-src 'none'; object-src 'none'; base-uri 'self'; form-action 'self' https://accounts.google.com
```

No `report-uri` / `report-to` endpoint yet: violations show in the browser console only.

All 34 were moved to delegated listeners in `public/assets/js/app.js`, keyed on data attributes:

`javascript:` URLs: none in views (the app actively strips them from user supplied links).

### Styles
| What | Where | Status |
|---|---|---|
| Site CSS | `assets/css/app.css, design-v2.css, place-v2.css` | `'self'` |
| Leaflet CSS | cdnjs (with SRI) | host allowed |
| `style="..."` attributes | about 2,000 across views | need `'unsafe-inline'` (attributes cannot carry a nonce) |
| `<style>` blocks | `views/travel_map.php`, `views/_scorecard.php` | covered by `'unsafe-inline'` |

Removing `'unsafe-inline'` from style-src is a large refactor and buys little: styles cannot run script.

### Fonts
Self hosted `assets/fonts/inter-latin.woff2`, `fraunces-latin.woff2`. No Google Fonts or other font CDN.

### Images
Same origin uploads (`/media/...`), `data:` URIs, Leaflet marker images, OpenStreetMap tiles
(`https://tile.openstreetmap.org`), imported place and city photos from arbitrary https hosts
(Wikimedia Commons and others, stored as URLs), and the optional R2 public base URL. Hence
`img-src 'self' data: blob: https:`.

### Connect
`fetch` and `sendBeacon` go to same origin only: `/suggest/*`, `/push/subscribe`, `/event`,
`/suggest/click`, the mention lookup, and `assets/data/world-map.json`. Push subscription goes
through the browser's push service, which CSP does not govern.

### Frames and forms
No `<iframe>`, `<embed>` or `<object>` anywhere. Every form posts to the same origin. Google sign
in is a link to `/auth/google`, which redirects to `https://accounts.google.com`; that host is in
`form-action` in case a form submission ever chains into the OAuth redirect.

### Third parties checked and absent
No analytics script (tracking is server side, `rmt_track`), no Cloudflare Web Analytics beacon
(checked production HTML 2026-10-30), no Google Identity Services client script, no Resend client
code (mail is server side), no CDN other than cdnjs for Leaflet.
