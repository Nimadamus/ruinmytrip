# Facebook, the next execution channel

Reddit is blocked from this machine. Facebook is not blocked, but **no personal Facebook account
exists for this work**, and that matters more than the block does: groups are posted into by people,
not by Pages. The only Facebook asset here is the TrustMyRecord Page, which is a sports betting
brand, cannot post into travel groups, and would be the wrong voice if it could.

So these five are finished and waiting on one thing only: a person with a normal Facebook account.

## Before any of them is posted

1. **Read the group's pinned rules.** Most travel groups ban links outright, some allow them in a
   comment, a few allow them in the body with disclosure. If the rule is ambiguous, do not post.
2. **Be a member for a while first.** A day old account posting a link is removed and the account is
   flagged. If the account is new to the group, comment on other people's posts for a week first.
3. **One group at a time.** Never the same text twice. Never five groups in an evening.
4. **Disclose.** Every post below says plainly that the author built the thing. A travel group will
   forgive self interest that is stated and will not forgive it hidden.
5. **If a moderator removes it:** record the reason in `docs/ACQUISITION_EXPERIMENTS.md`, do not
   repost, do not argue.
