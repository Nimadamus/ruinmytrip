# Ticket and entry-fee fact check (2026-11-07)

Ten blog posts were checked against official sources only. The full detail, with source URLs and quotes, is in `ticket_facts.json`.

**How the posts were chosen.** The repo docs show Search Console impressions only for the excluded test pages (tokyo-skytree, gold-museum-san-jose). So the order follows KEYWORDS.md (Venice, Park Guell, Sagrada Familia, Eiffel, Anne Frank) and then fame. No blog post exists for the Louvre or the Book of Kells.
