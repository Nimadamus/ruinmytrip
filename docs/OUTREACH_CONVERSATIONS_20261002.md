# Outreach: real conversations where RuinMyTrip helps (2026-10-02)

Source: r/travelpartners posts from 2026-09-25 to 2026-10-02 (read through the Arctic Shift
archive; Reddit itself is blocked from this machine). r/travelpartners is people posting a city and
dates and hoping someone overlaps. Most posts get 0 or 1 replies. Several of them overlap EACH
OTHER and do not know it. That is exactly what RuinMyTrip does, so the honest, useful reply is:
point people at each other first, mention the site second, say it is ours.

## Rules for every reply

* Reply only where there is a real overlap or a real answer. No reply that is only a link.
* The useful part (the other posts with overlapping dates) comes first and works without the site.
* Disclose: "I'm building a site for this" (it is Nima's). Never pretend to be a user.
* One reply per thread, never a DM unless the person asks. Never the same text pasted twice.
* Check the subreddit sidebar rules on the day. If self promotion is not allowed there, post the
  overlap part only, without the link. A helpful reply with no link still builds the account.
* Posted by Nima from his own Reddit account (this machine cannot reach Reddit).
* Link: `https://ruinmytrip.com/buddies?dest=<city>&utm_source=reddit&utm_campaign=travelpartners&utm_content=<city>`
